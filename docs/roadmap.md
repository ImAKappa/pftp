# Roadmap

## Overview

Learning programming isn't a linear thing

There will be lot's of doubling back, and running in circles, taking detours.

There is no real destination, but somewhere along the journey you gain enough experience
to understand programming and how to apply it to your problems.

## Plan

Start with a problem:

    I'm an office worker.
    I have over 300 files in my downloads folder and I really need to clean it up.
    I want to sort the files into different categories.
    Audio files, like mp3 and wav should be bundled together, images should be together, documents together, etc.
    Oh, and I also want the file names to have the last modified date.

    
Or a different problem:

    I'm a teacher and I have 50 test questions prepared in a spreadsheet.

    45 of those are multiple choice, 5 are short answer
    But I don't want to give everyone the same order of questions.
    Instead I want to create different versions of the test where the order of test questions is different.
    This will make it harder for the students to copy off each other.

    But the short answer should always come after the multiple choice, no matter the test version.

    Also, I need to make sure I have the correct answer key for each version.
