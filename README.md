# Python for the People

An introduction to Python for people with _zero_ programming experience.

View the tutorial at [https://imakappa.github.io/pftp/](https://imakappa.github.io/pftp/)

## Repository Structure

- `.github` Github Actions configuration
- `codealongs` Python source code for code alongs
- `docs` Source notes for the tutorial
- `ideas` Notes on ideas for the tutorial/upgrades to core library
- `pftp` core library for automation and writing utilities
- `teaching` Notes on teaching
- `test` automated testing
